# Preferências do Usuário & Workflow

## Workflow de Desenvolvimento & Git
- **Branch Principal de Trabalho:** Todas as alterações finalizadas e testadas devem ser commitadas diretamente na branch `dev`.
- **Mensagens de Commit:** Commits descritivos em português ou inglês seguindo o padrão semantic-commit (ex: `feat(header): ...`, `fix(category): ...`).

## Design & UI Preferences
- **Navbar / Cabeçalho Superior:** Simplificado para conter os botões rápidos principais: `Todas as Categorias` (drawer), `Ofertas & Saldão`, `Feminino ▾`, `Masculino ▾`, `Infantil ▾`.
- **Mega-Menu sem Divisões Artificiais:** O usuário prefere exibir **diretamente o nome das subcategorias cadastradas no banco de dados**, organizadas em um grid dinâmico e limpo, sem seções ou colunas engessadas.
- **Visualização de Pedidos Sem Bloqueios:** As informações dos produtos comprados devem aparecer abertas e visíveis imediatamente ao carregar "Meus Pedidos" e o painel de vendas.
- **Painel Administrativo Limpo e Sem Redundâncias:** Unificação dos controles de pedidos em um único seletor claro de "Etapa do Pedido", evitando controles repetidos de pagamento/envio.
- **Acesso Rápido ao Cliente:** Link direto com o WhatsApp do cliente nos cards de pedidos para facilitar o pós-venda.
- **Idioma de Comunicação:** Português (Brasil).
